# 🍝 Italian Restaurant Website

A responsive Italian restaurant website built as a frontend development practice project. The website provides an elegant interface inspired by Italian cuisine, showcasing restaurant content through a clean and visually appealing design.

## ✨ Features

- Responsive website layout.
- Clean and modern user interface.
- Restaurant-themed design.
- Interactive elements using JavaScript.
- Structured HTML and custom CSS styling.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive layouts.
- **JavaScript** – Interactive functionality.

## 📂 Project Structure

```text
Italian-Restaurant/
│
├── Assist/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/MahmoudAmer0a/Italian-Restaurant.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Italian-Restaurant
   ```

3. Open `index.html` in your browser.

## 🎯 Project Purpose

This project was created for frontend development practice, focusing on improving HTML, CSS, and JavaScript skills while building a restaurant-themed website.
